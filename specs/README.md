# Specs

Write a spec here before you start any non-trivial change. The `sdlc` skill (`.agents/skills/sdlc/`) walks through the full lifecycle.

Filename: `NNNN-short-title.md`, using the next free number (for example `0001-mcap-import.md`).

Each spec covers:

- **Goal**
- **Acceptance item**: which entry in `acceptance/checklist.md` this serves
- **Inputs and outputs**
- **Quality bar**: durable code, application code, or both. Note any schema or data-layout change.
- **Acceptance criteria**
- **Verification**: the commands that prove it is done
- **Open questions**: each with an owner
- **Plan**: the slices, added after the spec is agreed
